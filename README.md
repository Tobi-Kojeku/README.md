Health Data Analyst
-------------------

CORE FOCUS

Research analytics: descriptive, causal, predictive, and epidemiology-oriented analysis

\- Clinical research support: statistical analysis for protocol development, study design, and results discussion

\- Monitoring and Evaluation: indicator analysis, data quality/validation, and reporting to support learning and accountability

\- Healthcare service improvement: evaluating delivery performance and translating findings into recommendations

\-Communication and visualization: clear, publication-ready tables, figures, and narratives for stakeholders

TOOLS/METHODS

I use REDCap, SQL (via DBeaver), Stata, Python, R, Power BI, and NVivo to build reproducible workflows for data preparation, analysis, and reporting. I emphasize robust data validation, GCP/ICH trained in ethical handling of sensitive information (de-identification/aggregation), and transparent methodology.
